# AgriMitra AI 🌱

AI-powered agricultural intelligence and farmer marketplace, starting with West Bengal.

## Product scope
- Soil intelligence and soil-report analysis
- Crop suitability and profitability recommendations
- Crop disease screening with expert escalation
- Weather-aware farming calendar
- Bengali-first agricultural assistant
- Farmer-to-buyer marketplace
- Farm economics and government-service discovery

## Repository layout
- `frontend/` — React + Vite responsive web application
- `backend/` — FastAPI application foundation
- `ml/` — model training and inference pipelines
- `docs/` — architecture, API and data documentation
- `infrastructure/` — container and deployment configuration

## Frontend quick start
```bash
cd frontend
npm install
npm run dev
```

Dashboard values are deliberately empty until connected to trusted data sources. Never use demo data for real agricultural decisions.
